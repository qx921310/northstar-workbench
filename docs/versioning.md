# 版本与更新

北极星使用 `主.次.修订` 三段版本。需要安装桌面端母包时，第一个数字加一，其余保留；同一母包的界面热更新每次将最后一个数字加一。中间数字暂保留。此为项目约定，并非按 SemVer 的兼容性语义使用。

桌面端版本是已安装母包版本；签名界面包按该母包版本隔离。热更新的应用显示版本是 `母包版本的修订号 + 已确认界面包修订号`，仅在加载成功并确认后显示；失败或回滚会显示上一个已确认版本。界面修订号从 1 开始连续递增。每个包的签名清单包含母包版本、界面修订号、计算出的应用版本和代码提交，发布资源与签名不可覆盖。

构建前提交并检查工作区；执行 `scripts/build-ui-update.ps1 -Revision N` 生成签名包，再执行 `scripts/publish-ui-update.ps1 -Revision N`。发布到 `ui-v<母包版本>` 的 GitHub Release，其资源 `ui-N.zip` 与 `ui-N.zip.sig` 对应上述完整版本。母包仍通过正式 Release 发布，包含签名的安装包和更新清单。不要将密钥、凭据或 Vault 内容提交到仓库。
